This guide takes you from nothing to a working voice agent you have talked to, using Claude. You do not write a prompt or touch any settings. You describe the agent, answer a few questions, and Claude builds it in Whispey for you.

**What you will do**

1. [Get your access from Pype](#step-1-get-your-access-from-pype)
2. [Connect Whispey to Claude](#step-2-connect-whispey-to-claude)
3. [Build the agent in a Claude chat](#step-3-build-the-agent-in-a-claude-chat)
4. [Open it in Agent Studio and call it](#step-4-open-it-in-agent-studio-and-call-it)
5. [Improve it by asking Claude](#step-5-improve-it-by-asking-claude)

Allow about fifteen minutes the first time.

## Step 1: Get your access from Pype

The Pype team sets up your access and sends you two things:

- **The server address**: where Claude connects to reach Whispey.
- **Your key**: proves who you are, and lets Claude build and change agents in your project.

Don't have them yet? Ask your Pype contact, or open **Help Center** in Whispey (the question-mark icon at the top of the left sidebar) and ask for MCP access.

:::warning Keep your key secret
Anyone with your key can build and change agents in your project. Don't paste it into a chat, a shared document or a screenshot. If it leaks, tell the Pype team and they will replace it.
:::

## Step 2: Connect Whispey to Claude

You do this once. After that, Whispey is available in every Claude chat. It works the same in the Claude desktop app and on claude.ai.

<Tabs groupId="claude-plan">
<TabItem value="personal" label="Free, Pro or Max" default>

### Add the connector

1. In Claude, go to **Customize** → **Connectors**.
2. Click **+ Add**, then **Add custom connector**.
3. Fill in the first screen:
   - **Name**: `Whispey`. This is the name you will see in your connectors list.
   - **Remote MCP server URL**: the server address Pype gave you.
4. Click **Continue**.
5. Claude checks the server and shows the sign-in settings it found. Leave them as they are and click **Continue**.
6. On the next screen, set:
   - **Authentication**: **Sign in now**.
   - **OAuth client**: **Register automatically**.
   - **Request headers**: leave empty.
7. Click **Add**.

### Sign in with your key

Because you chose **Sign in now**, a Pype page opens straight away. It is titled **Pype MCP** and says **Authorize access to your voice analytics**.

1. In **Your Pype API Key**, paste your key. It starts with `pype_`.
2. Click **Authorize**.

Pype checks the key and sends you back to Claude. **Whispey** now appears in **Customize** → **Connectors**.

If the key is wrong, the Pype page says so. Paste it again, with no spaces before or after.

:::note Free plan
The Free plan allows one custom connector. If you already have one, remove it first or use a paid plan.
:::

On Team and Enterprise plans, an owner adds Whispey once for the whole organization. Each person then connects with their own key.

### Owner: add Whispey for the organization

Only an **Owner** or **Primary Owner** can do this. On Enterprise, so can anyone whose custom role includes **Manage access to Libraries**.

1. Go to **Organization settings** → **Connectors**.
2. Click **Add**.
3. Hover over **Custom**, then select **Web**.
4. Fill in:
   - **Name**: `Whispey`
   - **Remote MCP server URL**: the server address Pype gave you.
5. Click **Continue**.
6. Leave the detected sign-in settings as they are and click **Continue**.
7. Set **Authentication** to **Sign in when needed** and **OAuth client** to **Register automatically**. Leave **Request headers** empty.
8. Click **Add**.

Do not put a key in **Request headers**. Everyone in the organization would then share that one key.

### Everyone: connect with your own key

1. Go to **Customize** → **Connectors**.
2. Find **Whispey**. It has a **Custom** label.
3. Click **Connect**.
4. A Pype page opens, titled **Pype MCP**. In **Your Pype API Key**, paste your own key and click **Authorize**.

You are sent back to Claude, and Whispey shows as connected for you.

<TabItem value="code" label="Claude Code">

1. In your terminal, run:

   ```bash
   claude mcp add --transport http whispey <server-address>
   ```

   Replace `<server-address>` with the address Pype gave you. Add `--scope user` before `whispey` to use it in every project on your computer, not just the current folder.

2. Start Claude Code by typing `claude`.
3. Type `/mcp` and press Enter. You see a list of servers, with **whispey** marked as needing sign-in.
4. Choose **whispey**, then **Authenticate**. Your browser opens the **Pype MCP** page.
5. In **Your Pype API Key**, paste your key and click **Authorize**.
6. Back in the terminal, **whispey** shows as connected.

### Turn Whispey on in a chat

Connectors can be switched on and off for each conversation.

1. In a chat, click **+** at the bottom left of the message box.
2. Choose **Connectors**.
3. Make sure the toggle next to **Whispey** is on.

In Claude Code there is nothing to switch on. Whispey is available once it shows as connected in `/mcp`.

### Check that it works

In a new chat, type:

> List my Whispey agents.

Claude lists the agents in your project, or says you have none yet. Either answer means you are connected.

### Approving Whispey's actions

The first time Claude wants to use a Whispey tool, it shows the tool's name and asks for approval.

| Tool | What it does | Suggested answer |
|---|---|---|
| **list_agents**, **get_agent_details**, **query_call_logs**, **get_analytics_summary** and other "get" or "list" tools | Only read your data | **Allow always** |
| **create_agent**, **update_agent**, **create_flow_agent**, **update_flow_agent** | Create or change an agent | Allow once, each time, so you see every change |
| **raise_help_request** | Sends a request to the Pype team | Allow once |

To stop Claude using a tool at all, open **+** → **Search and tools** in the chat and switch that tool off.

### Remove or reconnect

Go to **Customize** → **Connectors**, click the three dots next to **Whispey**, and choose **Remove**. To change the address or key, remove Whispey and add it again.

## Step 3: Build the agent in a Claude chat

### Start

Open a new chat and type something like:

> Build me a new Whispey voice agent.

You can also start from the prompts menu:

- **Claude app or claude.ai**: click **+** at the bottom left of the message box, find **Whispey**'s prompts, and choose **pype-create-agent**.
- **Claude Code**: no menu needed. Just say "Create an agent" (or "Build me a Whispey voice agent") in the chat. Claude understands and starts.


Both start the same guided conversation. Claude follows a set of instructions from Pype, so the questions are always the same and in the same order.

### What Claude asks, in order

**1. Single agent or conversation flow?**

| Choose | When |
|---|---|
| **Single Agent** | One conversation with one clear goal. Most agents. |
| **Conversation Flow** | Separate stages with branches, lookups to your systems, transfers to a person or text messages. |

If you are not sure, say so. Claude helps you pick. The rest of this section is about a single agent. For a flow, see [Conversation flows](./build-an-agent#a-conversation-flow-step-by-step).

**2. Which use case?**

- **Lead Qualification**: an outbound call that checks whether a lead fits your criteria.
- **Appointment Reminder**: an outbound call to confirm, move or cancel an existing appointment.
- **Custom**: anything else.

Claude waits for your answer.

**3. What material do you have?** Claude asks three questions, one at a time. You can skip any of them:

1. "Do you have a flow document for this agent?" Paste it in, or attach the file.
2. "Any example lines you want the agent to say exactly?" For example, how it should introduce itself.
3. "Any real call transcripts I should learn from?" Paste one or two good calls.

For **Lead Qualification** and **Appointment Reminder** you can skip all three. Claude then uses Pype's ready-made template for that use case. For **Custom**, Claude needs at least one: there is no template to fall back on, so describe what the agent should do.

**4. Claude writes the prompt.** This happens inside Claude and can take a minute. Claude does **not** show you the whole prompt, which can run to thousands of words. Instead you get a short summary:

- The kind of call.
- How the conversation is structured.
- The variables it uses, such as `{{patient_name}}` or `{{appointment_time}}`.
- Any gaps it filled in for you.

If something is wrong, say so now, for example "Also remind them to bring their old reports". Claude updates the draft.

Claude also does two things without asking:

- **Gives the agent a spoken name**, such as Priya, if your material did not include one. This is the name the agent uses on the call.
- **Makes up test values** for every variable, written the way they will be spoken: "half past three in the afternoon", not "15:30". These let you call the agent straight away.

**5. A display name.** Claude suggests one, such as `Sunrise Clinic — Appointment Reminder`. Accept it or type your own. This is the name you see in Whispey; callers never hear it.

**6. Dispositions.** Claude suggests a short list of [dispositions](../analytics/dispositions): details Whispey pulls out of every call once it ends, such as whether the patient will attend or a new preferred date. Accept them, change them ("also record if they asked about parking"), or skip.

**7. Voice.** Claude does not ask. It uses the voice **Zara** and tells you that you can change it later.

**8. Claude creates the agent.** It asks to use **create_agent**. Approve it. Creating takes a few seconds.

### What you get back

Claude replies with:

- The agent's display name.
- **A link to Agent Studio**, on its own line. This is where you test the agent.
- The test values it set for each variable.

The agent is ready to call. You do not need to set anything up.


### An example conversation

Here is what a full build can look like, shortened.


> **You:** Build me a new Whispey voice agent.
>
> **Claude:** Happy to. First: a **Single Agent** (one conversation, one goal) or a **Conversation Flow** (stages, branches, transfers)?
>
> **You:** Single agent.
>
> **Claude:** Which kind? **Lead Qualification**, **Appointment Reminder** or **Custom**?
>
> **You:** Appointment reminder, for a dental clinic.
>
> **Claude:** Do you have a flow document for this agent? You can skip this.
>
> **You:** Skip.
>
> **Claude:** Any example lines you want reused exactly?
>
> **You:** It should always say "This is a reminder from Sunrise Dental" first.
>
> **Claude:** Any real call transcripts I should learn from?
>
> **You:** No.
>
> **Claude:** Here is what I drafted: an outbound reminder that confirms the appointment, offers to move it, or records a cancellation. Variables: `{{patient_name}}`, `{{doctor_name}}`, `{{appointment_date}}`, `{{appointment_time}}`. The agent introduces itself as Ananya. Suggested name: **Sunrise Dental — Appointment Reminder**. OK?
>
> **You:** Yes.
>
> **Claude:** I suggest recording: `will_attend`, `wants_reschedule`, `new_preferred_date`, `cancellation_reason`. Keep these?
>
> **You:** Keep them.
>
> **Claude:** Creating it now with the voice Zara. You can change the voice any time.
>
> *(Claude asks to use create_agent. You click Allow once.)*
>
> **Claude:** Done. **Sunrise Dental — Appointment Reminder** is live.
> Open it in Agent Studio: https://www.whispey.xyz/…/studio
> Test values: patient_name "Ramesh Kumar", doctor_name "Dr. Sharma", appointment_date "tomorrow", appointment_time "half past ten in the morning". You can call it now.

## Step 4: Open it in Agent Studio and call it

Click the Agent Studio link from Claude. Sign in to Whispey if asked. You land on your new agent's Studio page.

![Agent Studio for a new agent](/img/studio/workspace.jpg)

1. Click **Setup** at the bottom of the left panel. Check the **Voice** and the test values under **Variables**. Claude has already filled them in.
2. Click **Start call**. If you changed a value, the button says **Update and start** and saves your change first.
3. Allow the microphone when your browser asks.
4. Talk to the agent the way a real caller would. Try the awkward cases too: "I can't make it", "who is this?", "call me later".
5. Click **End call**.

After the call:

- **Last call** shows the full conversation.
- **Dispositions** on the right shows what was pulled out, such as `will_attend: no` and `new_preferred_date: Friday`.

See [Agent Studio](./agent-studio) for everything on the page.

## Step 5: Improve it by asking Claude

Go back to the **same Claude chat** and say what to change, in plain words:

> It sounded too formal. Make it warmer and shorter.

> If they want to reschedule, ask for a morning or afternoon preference first.

> Switch the voice to Raju.

> Also record whether they asked about parking.

> Change the test doctor name to Dr. Mehta.

Claude uses **update_agent** and changes only what you asked. Approve it, then call the agent again in Agent Studio to hear the difference. Each change restarts the agent, which takes a few seconds.

A new chat works too. Name the agent so Claude finds it, for example "In my Sunrise Dental reminder agent, make the greeting shorter."

:::note What Claude cannot do
Claude can change only agents it created. It cannot show you the current prompt, rename an agent, delete one, make phone calls or start campaigns. Rename in Agent Studio. Do the rest in the Whispey dashboard.
:::

## Troubleshooting

| What you see | What to do |
|---|---|
| Claude does not mention Whispey or its tools | In the chat, click **+** or the tools icon and switch **Whispey** on. In Claude Code, run `/mcp` and check whispey is connected. |
| The Pype page says the key is invalid | Copy the whole key again, with no spaces. |
| Claude can list your agents but cannot create one | Your key can only read data. Ask the Pype team for building access. |
| "Agent limit reached for this project" | Delete an agent you do not need, or ask Pype to raise your limit. |
| "Key is scoped to multiple projects" | Tell Claude which project to use. |
| The agent does not join the test call | It may still be starting after a change. Wait a few seconds and click **Start call** again. |
| Claude asks for your key in the chat | Do not paste it. Keys go only on the Pype sign-in page that **Connect** opens. |
| Anything else | Ask Claude to "raise a help request with Pype" and describe the problem. You get a reference number. |
