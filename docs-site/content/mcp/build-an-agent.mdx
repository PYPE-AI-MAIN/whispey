With building access, your AI assistant can create a voice agent from a conversation. You describe what the agent should do. The assistant asks a few questions, writes the prompt, creates the agent in Whispey and gives you a link to [Agent Studio](./agent-studio), where you can call it straight away.

You need [the MCP connection](./overview) set up with a key that has building access. For the whole path with screenshots and an example conversation, see [Build a voice agent from Claude](./quickstart). This page is the reference for each step.

## Start

In your assistant, type:

> Build me a new Whispey voice agent.

In Claude you can also pick the **pype-create-agent** prompt from the prompts menu (the **+** or **/** menu). It starts the same guided conversation.

## Choose the kind of agent

The assistant first asks which kind you want.

| Kind | Best for |
|---|---|
| **Single agent** | One prompt and one persona. Reminders, lead qualification, simple enquiries. |
| **Conversation flow** | A call with steps: branches, lookups to your systems, transfers to a person, messages. |

You can say which in your first message, for example "Build a single agent that reminds patients of tomorrow's appointment".

## A single agent, step by step

1. **Pick a use case.** Lead qualification, appointment reminder, or something custom.
2. **Share what you have** (optional). A flow document, example lines you like, or real call transcripts. For a custom agent, share at least one. The more you give, the closer the first draft.
3. **The assistant drafts the prompt.** It follows Pype's prompt guidelines and shows you a summary rather than the whole prompt.
4. **Name the agent.** The assistant suggests a name. Accept it or give your own.
5. **Choose dispositions.** The assistant suggests [dispositions](../analytics/dispositions), the details to pull out of every call, such as the outcome or a callback time. Accept, change or skip them.
6. **The agent is created.** It uses the voice **Zara** unless you ask for another. You get a link to Agent Studio and example values for the agent's variables, so you can test it at once.

## A conversation flow, step by step

1. **Describe the call.** Who calls whom and why, the steps, where it branches, and how it ends.
2. **Add the details.** Phone numbers to transfer to, systems to look things up in, and languages. If you do not have one yet, say so: the assistant marks it as a placeholder for later.
3. **Confirm.** The assistant reads the plan back to you. Correct anything before it builds.
4. **The flow is built.** This takes one to three minutes. You get a link to the flow, the names of its steps, and any warnings, such as a placeholder still to fill in.

To refine it, see [Workflow agents](../workflows/overview), or ask the assistant for changes.

## Test it

Open the link the assistant gave you. In [Agent Studio](./agent-studio), click **Start call** and talk to your agent in the browser.

## Change it later

Ask in plain words. The assistant changes only what you ask for.

- "Switch the voice to Raju."
- "Make the greeting shorter and warmer."
- "Add a disposition for the callback time."
- "Change the clinic name variable to Sunrise Clinic."
- For a flow: "After they confirm, send them to the payment step."

Each change redeploys the agent. A flow is only redeployed if the new version passes its checks.

:::note
Your assistant asks before it creates or changes an agent, depending on its own settings. Read what it is about to do before you approve it.
:::

## Voices

Choose by name: **Zara**, **Vidya**, **Priya**, **Kavya**, **Raju**, **Srikant**, **Shubh** or **Rahul**. You can change the voice later in your assistant or in [Agent Studio](./agent-studio).

## Limits

- Each project can have a set number of agents. If you reach it, the assistant says **Agent limit reached for this project**. Delete an agent or ask Pype for more. See [Billing and limits](../workspace/billing-and-limits).
- The builder can change only agents it created. Agents made in the dashboard are edited in the dashboard.
- It cannot rename an agent. Rename it in Agent Studio.
- It cannot delete agents, place phone calls or start campaigns.

## Stuck?

Ask your assistant to "raise a help request with Pype" and describe the problem. It files it with the Pype team and gives you a reference.
