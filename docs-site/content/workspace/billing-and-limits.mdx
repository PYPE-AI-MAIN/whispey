The dashboard does not show prices, invoices or plan boxes. This page lists the limits it does enforce.

## Agent limit

Each organization has a maximum number of active agents. The default for a new organization is 2. Your organization may have a different number.

When you reach it:

- The create agent button is turned off and says **Agent limit reached**.
- The create agent card shows **Limit Reached** and says **Agent limit reached. Delete an existing agent to create a new one.**
- If you try to create one another way, the request is refused with **Agent limit reached. Please upgrade your plan or deactivate an agent.**

To free a slot, delete an agent you no longer use. To raise the limit, ask Pype support.

## Who can create agents

The create agent button is shown to people on an allow list. If you are not on it, you may see a **Beta** badge, and choosing it opens a request for access instead of creating an agent.

## Campaign concurrency

A campaign's **Campaign Concurrency** can be from 1 to your organization's maximum. If none is set, the maximum is 5. The form shows **Cannot exceed** and the number if you go over.

See [Campaigns](./campaigns).

## Other limits you will see

| Where | Limit |
|---|---|
| Organization name | 100 characters |
| Organization description | 500 characters |
| Campaign name | At least 3 characters |
| Retry delay | 0 to 1440 minutes |
| Retry attempts | 0 to 10 |
| Backoff schedule | Up to 10 entries, each 5 to 1440 minutes |
